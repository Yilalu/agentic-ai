# Account Lockout Policy

**Policy ID:** POL-LOCK-001
**Category:** Account Lockout
**Effective Date:** January 1, 2026

## Purpose

This policy describes how locked customer accounts should be handled.

## Common Causes

- Multiple failed login attempts
- Security concerns
- Suspicious activity
- Password reset failure

## Required Information

- Customer ID
- Verification of identity

## Resolution

Customers must successfully complete identity verification before the account can be unlocked.

If suspicious activity is detected, the case must be escalated to the fraud team.

## Notes
The application does not unlock accounts automatically. It only recommends the next action.
