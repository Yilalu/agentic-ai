# Identity Verification Policy

**Policy ID:** POL-ID-001
**Category:** Identity Verification
**Effective Date:** January 1, 2026

## Purpose

This policy explains how customer identity should be verified before sensitive account actions.

## Verification Methods

Customers may verify their identity using:

- Customer ID
- Registered email address
- Date of birth
- Security questions
- One-time verification code

## Required Before

Identity verification must be completed before:

- Unlocking an account
- Processing fee refund recommendations
- Investigating fraud
- Viewing sensitive account information

## Verification Failure

If identity verification cannot be completed, the request should be escalated to a human representative.

## Notes
The application only recommends verification outcomes. No real authentication system is connected.
