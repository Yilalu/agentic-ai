# Fraud Investigation Policy

**Policy ID:** POL-FRAUD-001
**Category:** Fraud
**Effective Date:** January 1, 2026

## Purpose

This policy defines how suspected fraudulent banking activity should be handled.

## Examples of Fraud

- Unauthorized card transactions
- Identity theft
- Suspicious transfers
- Multiple failed login attempts
- Transactions from unusual locations

## Required Information

- Customer ID
- Transaction ID (if applicable)
- Description of suspicious activity

## Investigation

The application should retrieve customer and transaction information before generating a recommendation.

## Escalation Rules

The following always require human review:

- Transactions greater than $500
- Multiple suspicious transactions
- Identity theft reports
- Account takeover concerns

## Notes
No account freezing or financial action is performed automatically.
